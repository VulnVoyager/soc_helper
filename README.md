# SOC Helper Bot
Telegram-бот для автоматизированного анализа индикаторов компрометации (IoC)

## Зачем это нужно?
- Ускоряет триаж — не открывать 5 вкладок вручную
- Снижает ложные срабатывания — перекрёстная проверка
- Мобильный доступ — анализ из любого места
- Автоматизирует рутину — хеши, геолокация, репутация за 1 запрос

## Ключевые возможности
#### Поддерживаемые IoC
- IP-адреса (IPv4/IPv6)
- Домены
- URL
- Хеши файлов (MD5, SHA-1, SHA-256)
- Файлы (любой формат до 30 МБ → автоматический расчёт SHA-256)

### Интеграции
| Категория | Сервисы |
|----------|--------|
| **Репутация** | VirusTotal, AlienVault OTX, AbuseIPDB |
| **Инфраструктура** | Shodan, IPinfo |
| **Вредоносные URL** | URLhaus |
| **Сетевой шум** | GreyNoise (Community API) |

### Дополнительно
- **Оценка риска**: `🟢 Низкий` / `🟡 Средний` / `🔴 Высокий`
- **Кэширование** (1 час) — повторные запросы мгновенны
- **Команда `/flush`** — принудительное обновление данных
- **Безопасность**: временные файлы удаляются, поддержка `ALLOWED_USER_IDS`
- **Человекочитаемые отчёты** с кликабельными ссылками

- ## Установка

1. **Получи API-ключи**:
   - [VirusTotal](https://www.virustotal.com/) (обязательно)
   - [AbuseIPDB](https://www.abuseipdb.com/) (обязательно)
   - [Shodan](https://shodan.io/) (опционально)

2. **Создай бота** через [@BotFather](https://t.me/BotFather)

3. **Заполни `.env`**:
   ```env
   BOT_TOKEN=ваш_токен_из_BotFather
   VIRUSTOTAL_API_KEY=ваш_virustotal_ключ
   ABUSEIPDB_API_KEY=ваш_abuseipdb_ключ
   # SHODAN_API_KEY=ваш_shodan_ключ (опционально)
   ALLOWED_USER_IDS=123456789  # ваш Telegram ID

4. **Запусти**
   ```
       pip install -r requirements.txt
       python main.py
   ```
